# Android — Слова 3.0.0

Android 7.0+, target/compile SDK 36, пакет `ru.bashkir.words`, versionCode 32. Игра и интерфейс скомпилированы в `libbashkir_words.so` для arm64-v8a, armeabi-v7a и x86_64. Android-слой предоставляет Canvas, ввод, хранилище, звук, датчики, доступность и напоминания. Словарь, архивы миграции, изображения и музыка находятся в APK.

## Подпись и обновление

Сертификат подписи выпуска SHA-256:

`3833621841ad9952edd62fc68ab0dc3b6d40f2990da8735cbbe38ad2d97f2c4a`

Android проверяет ту же подпись при установке обновления поверх 2.10.5. При первом запуске версия 3.0.0 читает `CapacitorStorage` и сохраняет дальнейший прогресс в отдельном хранилище. [Сведения о подписи 2.10.5](releases/2.10.5.md)

Ключи и пароли не входят в Git, APK или исходный архив. Для будущих выпусков используйте тот же доступный ключ; переход с него на другой сертификат потребует отдельного решения о миграции.

## Сборка

Установите JDK 21, Android SDK 36, Build Tools 36.0.0, Android NDK 28 или новее и стабильный Rust. Укажите SDK через `ANDROID_HOME` или `android/local.properties`. Установите Rust-цели и сборщик NDK.

```text
rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android
cargo install cargo-ndk --locked
android/gradlew.bat -p android :app:assembleRelease :app:testDebugUnitTest :app:lintDebug
```

На Linux используйте `./android/gradlew`. Перед подписью выровняйте APK через `zipalign -P 16`, затем проверьте сертификат и подпись через `apksigner verify --print-certs`.

## Системные функции

Нативные отступы учитывают системные панели и вырез экрана. Кнопки доступны через TalkBack и клавиатурную навигацию.

Датчик движения использует гравитационную проекцию из rotation vector, а не нестабильные углы Эйлера при вертикальном хвате. При пределе смещения центр следует за изменением хвата, затем плавно центрируется на неподвижной новой ориентации. После сворачивания и поворота экрана калибровка начинается заново.

Подарок доступен с полуночи; напоминание запланировано на 12:00 местного времени, не показывается после получения подарка в этот день. Android 13+ запрашивает право уведомлений после нажатия на подарок. Доставка может задерживаться системой: используется неточный будильник без специального доступа. Расписание восстанавливается после перезагрузки, обновления APK и изменения даты/часового пояса.

Музыка и эффекты включаются независимо. Музыка запускается после первого касания, останавливается при сворачивании и отключении, возобновляется при возвращении.
