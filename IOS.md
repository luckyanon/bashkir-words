# iPhone: сборка и установка

Версия для iPhone сохраняет игру 2.8.5: классику, хардкор, словарь, переводы,
фоны и локальный прогресс. Интерфейс и правила используются из общей игры;
нативная оболочка написана на Swift / WKWebView. Требуется iOS 17 или новее.
Mac для установки через xtool не нужен. Сохранения Android автоматически не переносятся.

## Готовая сборка

Workflow **iPhone build** компилирует приложение для физического iPhone и
симулятора на macOS. В артефакте **BashkirWords-iPhone** находятся:

- `BashkirWords-unsigned.ipa` — собранное приложение, которое ещё нужно подписать;
- `iphone-preview.png` — экран из симулятора;
- `ios-smoke.json` — результат проверки загрузки словаря, поля, подсказки и сохранения после перезагрузки.

Неподписанный IPA нельзя установить простым открытием файла на iPhone.
Apple ID, пароль, сертификаты и ключи не передаются в GitHub Actions.

## Windows + xtool

1. Включите поддержку виртуализации в BIOS/UEFI и компонент Windows
   «Платформа виртуальной машины», затем перезагрузите компьютер, если WSL
   сообщает `HCS_E_HYPERV_NOT_INSTALLED`.
2. Настройте поддерживаемую версию Linux в WSL, Swift и xtool по
   [официальной инструкции](https://xtool.sh/documentation/xtool/installation-linux/).
   Нужны также iOS SDK из архива Xcode, `usbmuxd` и подключение USB к WSL
   через USBIPD либо поддерживаемый мост устройств Windows.
3. Выполните `xtool setup` в WSL. Вход в Apple выполняется локально;
   не отправляйте пароль или код 2FA в чат. Условия и ограничения подписи
   зависят от учётной записи Apple.
4. Подключите iPhone по USB, разблокируйте, подтвердите доверие компьютеру.
5. Для уже готового IPA выполните в WSL:

   ```sh
   xtool install /путь/к/BashkirWords-unsigned.ipa
   ```

   `xtool install` подписывает приложение с настроенной учётной записью
   и устанавливает его на подключённое устройство.
6. При запросе включите **Настройки → Конфиденциальность и безопасность →
   Режим разработчика** и подтвердите перезагрузку. При предупреждении о
   недоверенном разработчике откройте **Настройки → Основные → VPN и
   управление устройством**, выберите свою учётную запись и подтвердите доверие.

Если Apple отклоняет идентификатор `ru.bashkir.words`, задайте собственный
уникальный идентификатор в `ios/xtool.yml` и `ios/Info.plist` перед новой сборкой.
Для сохранения прогресса при обновлении используйте тот же идентификатор
и ту же команду подписи. Удаление приложения удаляет его локальные сохранения.

## Сборка из исходников

В Windows (Node.js 24):

```powershell
npm ci
npm test
npm run build:ios
```

Далее в настроенной WSL:

```sh
cd /mnt/c/путь/к/bashkir-words/ios
xtool dev
```

`xtool dev` собирает, подписывает и устанавливает приложение. Для IPA без
установки: `xtool dev build --ipa -c release`. Для подписанного IPA добавьте
`--sign` после настройки своей учётной записи.

На Mac с Xcode можно собрать без входа в Apple:

```sh
npm ci
npm run build:ios
bash scripts/package-ios.sh iphoneos
```

Результат: `ios/build/iphoneos/BashkirWords-unsigned.ipa`.

## Что проверяется

Общие тесты проверяют правила и сохранения; отдельные тесты iOS проверяют
нативный адаптер сохранения, загрузку встроенных данных и события жизненного
цикла. Workflow компилирует ARM64 и запускает игру в симуляторе iPhone.
Движение фона, тактильный отклик, подключение USB и подпись требуют проверки
на физическом устройстве. Это сборка для личной установки; подготовка
публикации в App Store в данный этап не входит.
