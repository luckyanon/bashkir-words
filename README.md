# Слова — башкирская игра

Игра для браузера и Android. Текущая версия — **2.8.5** (Android versionCode 11). Все словарные данные, изображения и шрифты встроены; игровой процесс работает без сервера и учётной записи.

## Запуск веб-версии

Требуется Node.js 24.

```sh
npm ci
npm start
```

Откройте http://127.0.0.1:5173/. Для автономной веб-сборки выполните `npm run build`, затем `npm run preview`.

## Android

Требуются JDK 21 и Android SDK 36. Поддерживается Android 7.0 и новее.

```sh
npm ci
npm run build:android
npx cap sync android
```

Затем откройте папку `android` в Android Studio либо запустите Gradle-задачу `:app:assembleRelease` из этой папки (`gradlew.bat` в Windows, `./gradlew` в Linux/macOS). Укажите локальный путь к SDK в среде или `android/local.properties`.

Ключ подписи не хранится в репозитории. Для обновления ранее установленного APK требуется исходный ключ. Подробности: [ANDROID.md](ANDROID.md).

## Игровые правила

- Количество уровней не ограничено. В классике на поле от семи до двенадцати слов; остальные допустимые существительные засчитываются как бонусные.
- Длина самого длинного слова всегда соответствует количеству букв в круге.
- Максимальная длина: уровни 1–19 — 8 букв, 20–49 — 9, 50–69 — 10, 70–99 — 11, с уровня 100 — 12.
- После уровня 40 исключаются двухбуквенные слова; после уровня 80 — двух- и трёхбуквенные. Для круга из шести букв минимум три буквы в слове, из семи и более — минимум четыре.
- Слова могут повторяться на разных уровнях. БАЛ — мёд включается в поле, когда допускается правилами и составом букв; бонусным оно не бывает.
- Подсказка открывает случайную закрытую букву. Подарок даёт 100 монет раз в день со сбросом в местную полночь.
- Уфа доступна по умолчанию. Остальные фоны покупаются за монеты: Салават — 1000, Баймак — 1600, Деревня — 2400, У бабушки — 3000. В настройках доступны звук, анимации, движение фона и сброс прогресса.

Прогресс хранится на каждом устройстве отдельно. Новое устройство начинает с уровня 1 и 90 монет; обновление сохраняет собственный прогресс устройства. Облачное восстановление и перенос сохранений Android отключены.

## Режим «Хардкор»

Кнопка в главном меню открывает отдельное сохранённое поле. На нём размещаются все подходящие существительные с русскими значениями, от двух букв, без ограничения в 12 целевых слов. Выбираются только наборы с 30 и более словами; в текущей базе 686 таких наборов, максимум — 183 слова. Ограничения минимальной длины по размеру круга и этапу игры действуют только в классическом режиме. Предел длины самого большого слова по этапам сохранён. Номер набора «Хардкора» не показывается. Под заголовком расположен небольшой счётчик найденных слов поля в формате «125/150»; бонусы в него не входят.

Небольшой значок под балансом монет предлагает пересобрать текущий набор с подтверждением «Пересобрать уровень?». Поле может расти в обе стороны. Только в «Хардкоре» поле можно перемещать пальцем или мышью и масштабировать двумя пальцами; на компьютере также доступны колесо мыши и кнопки «+»/«−» справа. Поле занимает весь экран позади интерфейса и обрезается только краями экрана. Круг букв и кнопки остаются неподвижными. Зум меняет реальные размеры клеток, промежутков и шрифта, сохраняя чёткость. Классическое поле по-прежнему подстраивается под доступную площадь без зума. При отгадывании слово за пределами видимой области перемещается в неё без изменения выбранного масштаба.

Обычный уровень и поле «Хардкора» сохраняются отдельно. Монеты, подарок и настройки общие. Перегенерация не даёт награду. В «Хардкоре» за каждое впервые найденное слово поля (включая слова, открытые пересечениями) и за бонусное слово начисляется 1 монета; за завершение поля дополнительно начисляется 500 монет. Награды за слова и завершение выдаются однократно и сохраняются после перезапуска. Старые сохранения удерживают прежний баланс: уже выданные награды не пересчитываются, новые слова и завершения используют новые суммы. Покупки фонов общие для обоих режимов. Сброс прогресса очищает оба режима.

В классическом режиме все существительные с русскими значениями, которые подходят по буквам и допустимой длине, но не попали на поле, принимаются как бонусные. Ограничение в три слова сохраняется для исходного набора бонусов без русского значения; дополнительные существительные этим лимитом не ограничены. За каждое бонусное слово начисляется пять монет один раз на уровне. Повторный ввод показывает то же уведомление без повторной награды, в том числе после перезапуска или повторного прохождения. Сохранения с тремя исходными слотами наград совместимы с расширенным списком.

Режим «Хардкор» включён в текущий APK 2.8.5.

## Словарь и ресурсы

Используется актуальная база существительных от 8 октября 2026 года: 6 704 слова, 6 038 с русскими значениями, 2 729 подготовленных наборов букв. Основные файлы находятся в `public/data`; исходные подробные записи сохранены без изменений.

Происхождение и условия использования словарных данных: [public/ATTRIBUTION.md](public/ATTRIBUTION.md), [public/data/nouns-sources.json](public/data/nouns-sources.json). Сведения о визуальных ресурсах: [ASSETS.md](ASSETS.md); лицензия шрифтов: [FONT-LICENSE.txt](public/assets/FONT-LICENSE.txt).

## Проверки

`npm test` запускает 87 проверок правил, генерации, сохранений, жестов и движения фона. Результаты сборок и ограничения проверки описаны в [QA.md](QA.md). Движение фона на физическом телефоне пока не проверялось.

В репозиторий не входят зависимости, готовые сборки, личные сохранения, локальные настройки и ключи подписи.

В главном меню классический режим называется «Классика». Под кнопкой меню расположена компактная подсказка с лампочкой и ценой 20 монет. Работа без интернета сохраняется без отдельного уведомления.

Покупка фона требует подтверждения. После покупки он применяется, а цена исчезает с карточки; повторный выбор бесплатный. Ранее открытые фоны сохраняются при обновлении. Новые уровни больше не открывают фоны. Сброс прогресса сбрасывает покупки. Слева сверху в меню кнопка «Рейтинг» открывает окно «В разработке».
