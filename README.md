# Слова — башкирская игра

Игра для браузера и Android. Текущая версия — **2.8.3** (Android versionCode 9). Все словарные данные, изображения и шрифты встроены; игровой процесс работает без сервера и учётной записи.

## Запуск веб-версии

Требуется Node.js 24.

```sh
npm ci
npm start
```

Откройте http://127.0.0.1:5173/. Для автономной веб-сборки выполните `npm run build`, затем `npm run preview`.

## Android

Требуются JDK 21 и Android SDK 36. Поддерживается Android 7.0 и новее.

```sh
npm ci
npm run build:android
npx cap sync android
```

Затем откройте папку `android` в Android Studio либо запустите Gradle-задачу `:app:assembleRelease` из этой папки (`gradlew.bat` в Windows, `./gradlew` в Linux/macOS). Укажите локальный путь к SDK в среде или `android/local.properties`.

Ключ подписи не хранится в репозитории. Для обновления ранее установленного APK требуется исходный ключ. Подробности: [ANDROID.md](ANDROID.md).

## Игровые правила

- Количество уровней не ограничено. На поле не менее семи слов, вне поля — не более трёх бонусных.
- Длина самого длинного слова всегда соответствует количеству букв в круге.
- Максимальная длина: уровни 1–19 — 8 букв, 20–49 — 9, 50–69 — 10, 70–99 — 11, с уровня 100 — 12.
- После уровня 40 исключаются двухбуквенные слова; после уровня 80 — двух- и трёхбуквенные. Для круга из шести букв минимум три буквы в слове, из семи и более — минимум четыре.
- Слова могут повторяться на разных уровнях. БАЛ — мёд включается в поле, когда допускается правилами и составом букв; бонусным оно не бывает.
- Подсказка открывает случайную закрытую букву. Подарок даёт 100 монет раз в день со сбросом в местную полночь.
- Пять фонов открываются на уровнях 1, 20, 40, 60 и 80. В настройках доступны звук, анимации, движение фона и сброс прогресса.

Прогресс хранится на каждом устройстве отдельно. Новое устройство начинает с уровня 1 и 90 монет; обновление сохраняет собственный прогресс устройства. Облачное восстановление и перенос сохранений Android отключены.

## Словарь и ресурсы

Используется актуальная база существительных от 8 октября 2026 года: 6 704 слова, 6 038 с русскими значениями, 2 729 подготовленных наборов букв. Основные файлы находятся в `public/data`; исходные подробные записи сохранены без изменений.

Происхождение и условия использования словарных данных: [public/ATTRIBUTION.md](public/ATTRIBUTION.md), [public/data/nouns-sources.json](public/data/nouns-sources.json). Сведения о визуальных ресурсах: [ASSETS.md](ASSETS.md); лицензия шрифтов: [FONT-LICENSE.txt](public/assets/FONT-LICENSE.txt).

## Проверки

`npm test` запускает 69 проверок правил, генерации, сохранений, жестов и движения фона. Результаты сборок и ограничения проверки описаны в [QA.md](QA.md). Движение фона на физическом телефоне пока не проверялось.

В репозиторий не входят зависимости, готовые сборки, личные сохранения, локальные настройки и ключи подписи.
