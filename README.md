# Слова — башкирская игра

Локальная игра для браузера и Android. Версия 2.7.0 использует только пакет bashkir-nouns от 7 октября 2026 года. Старый словарь удалён из игровых ресурсов. Подписанный APK 2.7.0 включает новую базу и компактную раскладку; файл `../bashkir-words-2.7.0.apk` готов для установки.

В базе 10 374 существительных длиной 2–12 букв; 1 776 имеют русские значения. На поле 7–13 слов с русскими значениями, вне поля до трёх бонусных слов. В каждом наборе обязательно есть слово из всех букв круга. Прочие слова из базы, не выбранные для текущего уровня, не дают награды.

## Сложность

- Уровни 1–19: не более 8 букв.
- Уровни 20–49: не более 9 букв.
- Уровни 50–69: не более 10 букв.
- Уровни 70–99: не более 11 букв.
- С уровня 100: не более 12 букв.

Псевдовероятность размеров сохраняется: 40% уровней с пятью буквами, 40% с шестью, 15% с семью, 5% с восемью и более. Каждые 20 уровней содержат все категории. Из длинных наборов выбираются только допустимые на данном этапе.

Для 6 букв не используются слова из двух букв; для 7 и более — слова короче четырёх букв. Уровни бесконечны, последовательность воспроизводится из собственного сохранения устройства.

## Компактная раскладка

Новые поля строятся от длинного слова: остальные слова присоединяются к общему полю через подходящие буквы. Допускаются несколько корректных пересечений одного слова. Алгоритм сравнивает несколько вариантов и выбирает более связную и компактную форму. Отдельные слова размещаются рядом с полем, если присоединить их не удалось.

Слова уровня, бонусы и порядок букв круга сохраняются. Уже открытые и начатые поля остаются в прежней раскладке вместе с отгаданными словами и раскрытыми подсказками. Новый алгоритм применяется только на будущих уровнях. Перед обновлением сохранения создаётся отдельная резервная копия с ключом `before-layout-v2`.

Проверены все 277 наборов. В сравнении на 360 уровнях доля полностью связанных полей выросла с 0% до 96,11%, а средняя площадь поля уменьшилась с 73,49 до 49,81 клетки в ограничивающем прямоугольнике — на 32,2%. Все 64 теста проходят.

## Запуск

`npm start` открывает локальный сервер на http://127.0.0.1:5173/. `npm run build` обновляет автономную веб-версию; `npm run preview` запускает её. `npm test` проверяет правила, генерацию и сохранения.

При замене базы сохраняются номер уровня, пройденные уровни, монеты, подарок и настройки. Поля перестраиваются под существительные; совпадающие отгаданные слова остаются раскрытыми. До первого изменения сохранения хранится резервная копия с ключом before-nouns-v6. Новое устройство начинает с первого уровня и 90 монет.

## Данные

`public/data/game-lexicon.nouns.json` — индекс полного набора существительных. `nouns.full.json` — исходные подробные записи. `nouns-sources.json` и `public/ATTRIBUTION.md` — происхождение и условия источников. Игра и словарь работают без сервера и учётной записи.

Новый набор содержит сведения нескольких источников с различными условиями использования. Полные сведения доступны в окне «О словаре».
