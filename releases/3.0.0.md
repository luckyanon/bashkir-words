# Слова 3.0.0 для Android

[Скачать APK](https://github.com/luckyanon/bashkir-words/releases/download/v3.0.0/bashkir-words-3.0.0.apk) · [Контрольная сумма](https://github.com/luckyanon/bashkir-words/releases/download/v3.0.0/SHA256SUMS-3.0.0.txt)

Игра теперь работает как нативное Android-приложение без WebView. На Rust реализованы интерфейс, словарь, классика и хардкор, экономика, подсказки и сохранения. Приложение работает без сети.

Сохранение Capacitor читается при первом запуске. Игровые поля, найденные слова, монеты, подсказки и покупки проверены на сохранениях 2.10.5 и 2.10.3. Установка поверх 2.10.5 и продолжение игры проверены на эмуляторе Android 35.

Android 7.0+, пакет `ru.bashkir.words`, versionCode 32. Поддерживаются ARM64, ARMv7 и x86-64.
