# Слова 2.10.2 — Android

[Скачать APK](https://github.com/luckyanon/bashkir-words/releases/download/v2.10.2/bashkir-words-2.10.2.apk)

Возвращён старый интерфейс версии 2.9.5: фиолетовая цветовая схема, прозрачность, размытие, шрифты, размеры, расположение элементов, тексты и анимации.

По рекомендациям unslop изменены только радиусы кнопок и согласованы с ними баланс, служебные плашки, карточки и окна. Круг выбора букв и игровые клетки сохранили прежнюю форму. В CSS относительно старого оформления изменено ровно 25 значений `border-radius`; остальные свойства совпадают. [Отчёт об оформлении](../reports/interface-radii-2.10.2.md).

Все удаления слов из 2.10.0 и 2.10.1 сохранены. База и правила игры не изменились: 6527 слов, 5874 с русскими значениями, 2345 наборов классики. Обновление с 2.10.1 сохраняет прогресс, баланс, покупки, настройки, подсказки и бонусные награды без новой миграции базы.
