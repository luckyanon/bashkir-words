# Слова 2.10.3 — Android

[Скачать APK](https://github.com/luckyanon/bashkir-words/releases/download/v2.10.3/bashkir-words-2.10.3.apk)

Найденные слова теперь идут по времени нахождения: первое сверху, последнее снизу. Обычные и бонусные слова показываются вместе. При открытии список прокручивается вниз к последнему слову; после перевода возвращается на прежнюю позицию. Порядок сохраняется между запусками в обоих режимах.

Ранее игра не записывала общую хронологию: для уже найденных слов используется доступный прежний порядок, новые находки добавляются последовательно. Одновременно завершённые пересечения добавляются одной группой, введённое слово — последнее в ней.

Удалено ҠЫҘЫ («его/её дочь», притяжательная форма); ҠЫҘ сохранено. Остальные 6526 записей не изменены; 5873 имеют русский перевод, подготовлены 2344 набора классики. [Подробности удаления](../reports/dictionary-removals-2.10.3.md).

Добавлен воспроизводимый [аудит множественного числа](../reports/plural-audit-2026-11-13.md): 13 башкирских кандидатов с основаниями, отдельно русские переводы и неоднозначные случаи. Кандидаты оставлены для проверки; кроме ҠЫҘЫ ничего не удалено.

Сохранения из 2.10.1/2.10.2 и прежних выпусков переносятся с сохранением монет, уровня, покупок, настроек, подсказок и бонусных наград. Прежнее оформление и радиусы 2.10.2 сохранены.
